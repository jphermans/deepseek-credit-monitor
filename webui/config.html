DeepSeek API Key
Required for the account balance. Create one at platform.deepseek.com. Stored server-side only and never shown again after saving. Alternatively, store it as the DEEPSEEK_API_KEY secret in Agent Zero's secret store.
Refresh interval
How often the WebUI asks the plugin backend for a fresh balance.
Balance currency
Currency used for the main sidebar value and for threshold evaluation. DeepSeek may return USD, CNY, or both; every returned currency is always shown in the details popover.
Low-balance warning
Show a “Low” badge and a warning notification at or below this balance, in the selected currency.
Critical-balance warning
Show a “Critical” badge and an error notification at or below this balance, in the selected currency.
Show balance in WebUI
Display the persistent DeepSeek indicator in the sidebar.
